# aplikasi-restoran-azazel-java

Program Java sederhana untuk simulasi aplikasi restoran bertema Korea.

Project ini dibuat sebagai Tugas Praktik 2 mata kuliah Pemrograman Berbasis Desktop.

## Fitur
- Pemesanan makanan dan minuman
- Manajemen menu restoran
- Perhitungan diskon dan pajak
- Cetak struk pembayaran

## Bahasa Pemrograman
- Java
